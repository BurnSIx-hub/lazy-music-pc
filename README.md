# Lazy Music для Windows

Здесь лежат только выпуски — установщики Lazy Music для ПК. Кода в этом
репозитории нет.

**Поставить:** открыть последний выпуск в разделе
[Releases](https://github.com/BurnSIx-hub/lazy-music-pc/releases/latest),
скачать `LazyMusic-PC-<версия>-setup.exe` и запустить. Ставится в профиль
пользователя, права администратора не нужны.

**Обновляться:** приложение само проверяет эту страницу и предлагает
«Обновить». Каждый выпуск подписан, и перед установкой приложение
сверяет подпись: файл, подписанный не тем ключом, не поставится.
Библиотека, настройки и сопряжение с телефоном при обновлении
сохраняются.

---

## English

This repository holds only the releases — Lazy Music installers for the PC.
There is no code here.

**Install:** open the latest release in the
[Releases](https://github.com/BurnSIx-hub/lazy-music-pc/releases/latest)
section, download `LazyMusic-PC-<version>-setup.exe` and run it. It installs
into the user profile, no administrator rights needed.

**Updates:** the app checks this page by itself and offers “Update”. Every
release is signed, and the app verifies the signature before installing:
a file signed with a different key won’t install. Your library, settings
and phone pairing are kept on update.

The app follows the Windows language: Russian on a Russian Windows, English
otherwise. You can change it in Settings → Language.
