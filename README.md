# Lazy Music для Windows

Здесь лежат только выпуски — установщики Lazy Music для ПК. Кода в этом
репозитории нет.

**Поставить:** открыть последний выпуск в разделе
[Releases](https://github.com/BurnSIx-hub/lazy-music-pc/releases/latest),
скачать `LazyMusic-PC-<версия>-setup.exe` и запустить. Ставится в профиль
пользователя, права администратора не нужны.

**Обновляться:** приложение само проверяет эту страницу и предлагает
«Обновить». Каждый выпуск подписан, и перед установкой приложение
сверяет подпись: файл, подписанный не тем ключом, не поставится.
Библиотека, настройки и сопряжение с телефоном при обновлении
сохраняются.
